# Optional CitrusScholar integration

Pin this independent repository by commit, the Python lock and the Worker image. Discover `SKILL.md` through the host's normal Agent Skills loader. Install `citrus-data-audit` into the authorized Code worker and resolve duplicate ownership of the `citrus_audit` import when replacing `citrusscholar-support[audit]`. The latter distribution also provides other packages, so remove only the overlapping package ownership when updating its build.

Resolve access to attachment bytes and output destinations with the host's normal file and artifact APIs. Call `audit_table` or `review_bytes` inside authorization. Retain exact ranges, SHA-256, rule receipts and artifact IDs in the host's workflow. File and result authorization are host duties. A custom chart may use saved table arrays and coordinate vectors directly. Native specialized result admission is optional for the specialized review UI. Standard Code results can be delivered through the common artifact path.

`audit_frame`, `audit_duplicates`, `audit_group_outliers`, `audit_selected_checks`, `export_reviewed_workbook`, `parse_plan` and `compare_bound` remain available for existing adapters. `citrus_audit.data_audit_rules.BASELINE_RULES` identifies the original 38 entries. Rule adapters that assumed the complete `RULES` mapping had exactly 38 entries should use the baseline tuple or recognize the four additions. `IntegrityTable.key` keeps the legacy `(source_id, sheet)` shape when region identity is absent and adds an identity for region tables. Workbook receipts retain `marked_locations` (distinct finding references) and add `marked_cells` (physical marked cells).

Snapshot schema `2.0.0` remains readable. New fields include `report_sha256`, `checklist`, and OOXML formula metadata. CLI stdout is deliberately compact and full material is written to the explicit output path. Update consumers of the former inline `tables` or export `receipt` payload accordingly. The license and source provenance are in the distribution and repository.
